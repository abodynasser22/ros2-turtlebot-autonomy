# Code changes for the resubmission

Every change is an addition. With default parameters the controller solves the same problem and
sends the same commands as the submitted code. The submitted copy in `submission/` is not touched.

## `ros2_ws/src/r7021e_project/r7021e_project/mpc_node.py`

Line numbers are in the changed file.

| lines | what | default | effect at the default |

Check that the defaults are unchanged:

- `python3 mpc_node.py --smoke`: all five scenarios solve, with the same first commands as before
  (v = 0.220, omega = 0.000).
- `analysis/plot_run.py` still loads the node and grades `bags/s3_future_1` to the Table 2 numbers.
- Default S3 runs with the changed node (`resubmission/bags/wp2/wp2_default_1..3`): PASS, 11.5,
  11.5, 11.4 s, clearance +0.049, +0.052, +0.037 m. Same verdict as the baseline in
  `2026-10-30-experiment-log.md`.

The `ccw_bias` term had two earlier versions on 29 Oct, used only by the exploratory bags
`wp2_ccw_try1`, `wp2_ccw_try_w0.1`, `wp2_ccw_try_w0.3` (ungated `min(th, 0)^2`) and `wp2_ccw_try_b1_f05`
(a free band, with a second parameter `ccw_free` that no longer exists). The final code keeps only the
gated form above. All three versions were off by default.
